# LegalLens AI – Prompts Registry
**Directory:** `/prompts`  
**Purpose:** Versioned, decoupled prompt templates for agent cognitive tasks.

All prompts in LegalLens AI are decoupled from application source code into semantic-versioned YAML/Markdown definitions.

## Prompt Schema & Organization
- `extraction/`: Document understanding, structural clause tagging, and OCR cleanup.
- `research/`: Hybrid RAG query formulation, India Code statutory search, and DigiSCR case law queries.
- `risk/`: Qualitative IRAC synthesis, contractual ambiguity explanation, and liability exposure attribution.
- `verification/`: Adversarial evidence verification, judicial treatment cross-checks, and citation grounding.
- `simulation/`: Counterfactual scenario perturbation and breach simulation prompts.
- `report/`: Executive memorandum generation and formal redline diff drafting.
